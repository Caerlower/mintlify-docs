# TrustLine credit

On **testnet**, agents can use Fianza / TrustLine credit tools. These are **not enabled on mainnet**.

| Tool | Role |
| --- | --- |
| `trustline_status` | Credit / position snapshot |
| `trustline_onboard` | Onboard for credit |
| `trustline_borrow` | Borrow against the line |
| `trustline_repay` | Repay borrowed amount |

Use a testnet token and `NEBULA_HUB=https://testnet.nebulaonchain.xyz`. See [Networks](/networks) and [Tools overview](/tools/overview).
