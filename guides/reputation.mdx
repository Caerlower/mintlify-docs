# Reputation

Nebula integrates Stellar8004 for on-chain agent identity and reputation.

| Tool | Role |
| --- | --- |
| `register_identity` | Create or refresh identity (idempotent) |
| `get_my_reputation` | Score, feedback count, unique counterparties |

Call `register_identity` once after funding, then use `get_my_reputation` anytime. See [Policy and identity tools](/tools/policy).
