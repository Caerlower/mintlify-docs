# Treasury and yield

Nebula keeps a **liquid** band for spend and can park the rest in [Blend](https://blend.capital/) for yield. Testnet uses XLM pools; mainnet supports XLM and USDC pools.

## Agent tools

| Tool | Role |
| --- | --- |
| `get_treasury_status` | Liquid vs Blend balances, threshold, APY |
| `blend_check_rates` | Current supply APY |
| `optimize_treasury` | Trigger a rebalance toward the configured threshold |
| `spending_report` | Recent activity including treasury moves |

## Dashboard only

| Control | Role |
| --- | --- |
| Liquidity threshold | Minimum liquid balance to keep |
| `blend_deposit` / `blend_withdraw` | Manual pool moves |

Agents cannot change the threshold or call deposit/withdraw via MCP.

Rebalancing also runs on activity (incoming funds / payments). Before large payments, call `get_treasury_status`; the Hub can recall from Blend as needed.
