# Pay with x402

Use `x402_fetch` when the agent should fetch a URL and pay any HTTP 402 challenge automatically. Use `x402_pay` when the agent already knows the exact USDC price.

## Prerequisites

- Funded wallet (XLM for fees; USDC for payments)
- USDC trustline open (Connect / dashboard if needed)
- Policy caps high enough for the payment

## Flow

```text
x402_fetch({ url, max_amount_usdc? })
→ Hub pays USDC if challenged → returns response body
```

Policy caps and optional human confirmation still apply. On `confirmation_required`, approve in the dashboard and poll `await_confirmation`.

See [Payment tools](/tools/payments).
