# Connect

Every agent needs a `nbl_live_…` bearer token from the Hub **Connect** page. The token is bound to that agent's ledger. Point MCP at the **same host** where you created it.

<Steps>
  <Step title="Create a token">
    1. Sign in at [testnet.nebulaonchain.xyz](https://testnet.nebulaonchain.xyz) or [mainnet.nebulaonchain.xyz](https://mainnet.nebulaonchain.xyz).
    2. Open **Connect** → create an agent → copy `nbl_live_…` (shown once; regenerate if lost).
  </Step>
</Steps>

## Environment

| Variable | Required | Description |
| --- | --- | --- |
| `NEBULA_TOKEN` | Yes | `nbl_live_…` from Connect |
| `NEBULA_HUB` | Recommended | Matching Hub host: `https://testnet.nebulaonchain.xyz` or `https://mainnet.nebulaonchain.xyz` |

<Warning>
  Do not use the apex domain (`nebulaonchain.xyz`) for MCP or `/mcp`. Apex product routes redirect and can drop Bearer tokens. See [Networks](/networks).
</Warning>

## Claude Desktop / Cursor (stdio)

```json
{
  "mcpServers": {
    "nebula": {
      "command": "npx",
      "args": ["-y", "nebulamcp-stdio"],
      "env": {
        "NEBULA_TOKEN": "nbl_live_…",
        "NEBULA_HUB": "https://testnet.nebulaonchain.xyz"
      }
    }
  }
}
```

Package: [`nebulamcp-stdio`](https://www.npmjs.com/package/nebulamcp-stdio). Restart Claude Desktop after edits; in Cursor, toggle the MCP server.

## Claude Code

Prefer remote HTTP MCP (no stdio package):

```text
POST https://testnet.nebulaonchain.xyz/mcp
Authorization: Bearer nbl_live_…
```

Or use the same `nebulamcp-stdio` JSON in `.claude/mcp.json` if you need local stdio.

## Remote MCP (Streamable HTTP)

For hosted agents that cannot run `npx`:

```text
POST https://testnet.nebulaonchain.xyz/mcp
Authorization: Bearer nbl_live_…
Content-Type: application/json
```

Use the mainnet host when the token was minted there.

## OAuth (hosted connectors)

Dynamic Client Registration on the ledger host:

| Step | Endpoint |
| --- | --- |
| Discovery | `GET /.well-known/oauth-authorization-server` |
| Register | `POST /api/oauth/register` |
| Authorize | `/authorize` |
| Token | `POST /oauth/token` (access tokens expire in 30 days) |

## Verify

Ask the agent to call `ping`, then `get_address`. On success you get a timestamp and a `G…` address.

If a token is exposed, revoke it in the dashboard and create a new one. The token alone cannot sign without Hub policy checks.
