This guide takes you from zero to a working Nebula connection in Claude Desktop or Cursor. By the end you will have an agent that can check its Stellar balance, get its wallet address, and make payments — all within the spending policy you define.

<Warning>
  Never put a Stellar secret key (`S…`) in your MCP configuration. Nebula is designed so that your agent only needs a `NEBULA_TOKEN`. Private keys stay inside the Nebula Hub at all times.
</Warning>

## Steps

<Steps>
  <Step title="Sign in to Nebula">
    Go to [nebulaonchain.xyz](https://nebulaonchain.xyz) and sign in. The Hub will provision a Stellar wallet for you automatically on your first login — no extra setup required.
  </Step>

  <Step title="Create an agent and copy your token">
    In the dashboard, open the **Connect** page and click **New Agent**. Give your agent a name (for example, `claude-desktop`), then click **Create**. 

    Copy the `nbl_live_…` token that appears. This is the only credential your agent will ever need. Store it somewhere safe — you can regenerate it from the dashboard at any time, but you cannot view it again after leaving this screen.
  </Step>

  <Step title="Add Nebula to Claude Desktop">
    Open your Claude Desktop configuration file. On macOS it is at `~/Library/Application Support/Claude/claude_desktop_config.json`; on Windows it is at `%APPDATA%\Claude\claude_desktop_config.json`.

    Add the `nebula` entry to the `mcpServers` object:

    ```json claude_desktop_config.json
    {
      "mcpServers": {
        "nebula": {
          "command": "npx",
          "args": ["-y", "@nebula/mcp"],
          "env": {
            "NEBULA_TOKEN": "nbl_live_…"
          }
        }
      }
    }
    ```

    Replace `nbl_live_…` with your actual token. Save the file and **restart Claude Desktop**.
  </Step>

  <Step title="Add Nebula to Cursor (optional)">
    If you use Cursor instead of (or alongside) Claude Desktop, open **Cursor Settings → MCP** and add the same configuration:

    ```json Cursor MCP config
    {
      "mcpServers": {
        "nebula": {
          "command": "npx",
          "args": ["-y", "@nebula/mcp"],
          "env": {
            "NEBULA_TOKEN": "nbl_live_…"
          }
        }
      }
    }
    ```

    Cursor picks up MCP server changes without a full restart — toggling the server off and on in settings is enough.
  </Step>

  <Step title="Verify the connection">
    In Claude Desktop (or Cursor), start a new conversation and ask:

    > "Can you call the Nebula ping tool and then get my wallet address?"

    You should see a response confirming Nebula is alive, followed by your Stellar public address (starting with `G`). If you see an error instead, double-check that the token in your config matches the one from the Connect page.

    <Tip>
      On a testnet wallet you can also ask your agent to call `request_funding` to get your Friendbot URL and top up the wallet with test XLM instantly.
    </Tip>
  </Step>
</Steps>
