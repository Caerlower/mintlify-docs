# Quickstart

Connect an agent on testnet, then call `ping` and `get_address`.

<Warning>
  Never put a Stellar secret key (`S…`) in MCP config. Only use `NEBULA_TOKEN`.
</Warning>

<Steps>
  <Step title="Create an agent token">
    Sign in at [testnet.nebulaonchain.xyz](https://testnet.nebulaonchain.xyz) → **Connect** → create an agent → copy the `nbl_live_…` token (shown once).
  </Step>
  <Step title="Add MCP config">
    Use [`nebulamcp-stdio`](https://www.npmjs.com/package/nebulamcp-stdio). Point `NEBULA_HUB` at the **same host** where you minted the token.

    ```json
    {
      "mcpServers": {
        "nebula": {
          "command": "npx",
          "args": ["-y", "nebulamcp-stdio"],
          "env": {
            "NEBULA_TOKEN": "nbl_live_…",
            "NEBULA_HUB": "https://testnet.nebulaonchain.xyz"
          }
        }
      }
    }
    ```

    - **Claude Desktop:** `~/Library/Application Support/Claude/claude_desktop_config.json` (macOS) or `%APPDATA%\Claude\claude_desktop_config.json` (Windows). Restart Claude after saving.
    - **Cursor:** Settings → MCP, or `~/.cursor/mcp.json`. Toggle the server off/on to reload.
  </Step>
  <Step title="Verify">
    Ask your agent to call `ping`, then `get_address`. You should get a timestamp and a `G…` Stellar address.

    On testnet, call `request_funding` for Friendbot instructions to top up XLM.
  </Step>
</Steps>
