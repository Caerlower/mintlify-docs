# Custody

Each agent gets an isolated Privy-managed Stellar wallet. Signing happens only inside the Hub after policy (and optional human confirmation) pass.

| Who | Holds |
| --- | --- |
| You (dashboard) | Privy session \+ agent ownership |
| Agent | `nbl_live_…` token or OAuth access token |
| Hub | Privy-authorized signing material |

The token authorizes tool calls. It cannot sign Stellar transactions by itself.

<Warning>
  Never put a Stellar secret key (`S…`) in MCP config, env files, or prompts.
</Warning>

If a token leaks, revoke it on **Connect** and create a new one. Funds stay behind Hub policy.
