# Introduction

Nebula is the treasury layer for AI agents on Stellar. Each agent gets an isolated wallet, a liquid spend band with optional Blend yield, and Hub-enforced policy before any spend is signed.

**Agents never hold private keys.** They present a `nbl_live_…` token (or OAuth). The Hub checks policy, asks for human confirmation when required, signs with Privy custody, and submits to Stellar.

## What you get

| Capability | What it means |
| --- | --- |
| Custody | One Privy-managed Stellar wallet per agent |
| Twin networks | Separate testnet and mainnet agents, policy, and history |
| Policy | Per-tx / daily USDC caps, allow/deny lists, pause |
| Payments | Transfers, XLM↔USDC swaps, x402, MPP sessions |
| Treasury | Liquid band \+ Blend yield on idle funds |
| Reputation | Stellar8004 on-chain identity and score |
