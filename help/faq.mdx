# FAQ

<AccordionGroup>
  <Accordion title="What package do I install?">
    Use [`nebulamcp-stdio`](https://www.npmjs.com/package/nebulamcp-stdio) with `npx -y nebulamcp-stdio`. There is no `@nebula/mcp` package.
  </Accordion>

  <Accordion title="Which Hub URL should I use?">
    The host where you minted the token: `https://testnet.nebulaonchain.xyz` or `https://mainnet.nebulaonchain.xyz`. Do not use apex for MCP. See [Networks](/networks).
  </Accordion>

  <Accordion title="Do agents hold private keys?">
    No. Keys stay in Hub custody (Privy). Agents only present `nbl_live_…` or OAuth.
  </Accordion>

  <Accordion title="Can my agent change spending caps?">
    No. Caps, allow/deny, and pause are dashboard-only. Agents call `get_policy_status`.
  </Accordion>

  <Accordion title="Can my agent deposit to Blend?">
    Not via MCP. Deposit/withdraw and liquidity threshold are dashboard-only. Agents can call `optimize_treasury` and read status.
  </Accordion>

  <Accordion title="Why did a transfer ask for approval?">
    Amount, destination risk, or policy thresholds triggered [confirmations](/concepts/confirmations). Approve in the dashboard and poll `await_confirmation`.
  </Accordion>

  <Accordion title="Is TrustLine available on mainnet?">
    No — testnet only for now.
  </Accordion>
</AccordionGroup>
