# Tools overview

Agents discover tools over MCP. Every call goes to the Hub on the agent's ledger host, which enforces policy, confirmations, and signing.

## Response status

| Status | Meaning |
| --- | --- |
| `ok` | Success |
| `error` | Failed; see `reason` |
| `confirmation_required` | Approve in the dashboard, then `await_confirmation` |
| `rejected` | Human denied the confirmation |

## MCP tools

| Category | Tools |
| --- | --- |
| [Wallet](/tools/wallet) | `help`, `ping`, `get_address`, `check_balance`, `request_funding`, `transfer` |
| [Payments](/tools/payments) | `get_swap_quote`, `swap`, `x402_fetch`, `x402_pay`, `mpp_open_session`, `mpp_fetch`, `mpp_status`, `mpp_close_session` |
| [Treasury](/tools/treasury) | `get_treasury_status`, `blend_check_rates`, `optimize_treasury`, `spending_report` |
| [Policy and identity](/tools/policy) | `get_policy_status`, `await_confirmation`, `register_identity`, `get_my_reputation`, `trustline_*` (testnet) |

## Dashboard only

Not available to agent MCP tokens:

| Control | Purpose |
| --- | --- |
| Policy mutations | Caps, allow/deny, pause, deploy |
| `blend_deposit` / `blend_withdraw` | Manual Blend moves |
| Liquidity threshold | Minimum liquid balance |

`optimize_treasury` **is** available to agents.

## HTTP

```bash
curl -X POST https://testnet.nebulaonchain.xyz/api/tools/check_balance \
  -H "Authorization: Bearer nbl_live_…" \
  -H "Content-Type: application/json" \
  -d '{}'
```

Use the mainnet host when the token was minted there. Never use apex for tool calls.
