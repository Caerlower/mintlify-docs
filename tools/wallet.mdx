# Wallet tools

| Tool | Params | Notes |
| --- | --- | --- |
| `help` | optional topic | Lists tools and short summaries |
| `ping` | — | Health check; returns timestamp |
| `get_address` | — | Agent `G…` address \+ network |
| `check_balance` | — | Live XLM / USDC balances |
| `request_funding` | — | Friendbot URL (testnet) or funding guidance |
| `transfer` | `destination`, `amount_xlm`, optional `memo`, `reason` | Counts toward USDC policy caps via FX; may need confirmation |

See [Tools overview](/tools/overview) for status codes.
